# Política de privacidad de Utaha

Última actualización: 2026-11-16

Esta política explica qué datos guarda el bot Utaha ("el Bot") y para qué.

## 1. Datos que guarda el Bot

| Dato | Para qué se usa |
|---|---|
| ID del servidor de Discord | Separar la configuración y la reproducción de cada servidor |
| Volumen, rol DJ e idioma del servidor | Recordar la configuración entre sesiones |
| Listas de reproducción: nombre, ID del usuario creador y pistas (título, duración, enlace y miniatura) | Guardar y cargar las listas que crea cada usuario |
| Registros técnicos: fecha y hora, tipo de evento, descripción del error e ID del servidor | Detectar y corregir fallos |

## 2. Datos que el Bot no guarda

- No lee ni guarda el contenido de los mensajes.
- No graba ni guarda el audio de los canales de voz.
- No guarda tokens ni credenciales en los registros.
- No vende ni comparte datos con terceros con fines comerciales.

## 3. Servicios de terceros

Para reproducir música, el Bot envía a YouTube las búsquedas y enlaces que los usuarios piden. Discord procesa las interacciones con el Bot según su propia [Política de privacidad](https://discord.com/privacy).

## 4. Conservación y eliminación

- Las listas y la configuración se conservan hasta que el usuario borre la lista con /playlist delete o se solicite su eliminación.
- La cola de reproducción solo vive en memoria y se descarta al detener el Bot, al vaciar la cola o a los 10 minutos de perder la conexión de voz.
- Para pedir que se borren tus datos o los de tu servidor, escribe al contacto indicado abajo.

## 5. Seguridad

El token del Bot se guarda en variables de entorno y se excluye de los registros. Ningún sistema es totalmente seguro, así que no podemos garantizar una protección absoluta.

## 6. Cambios

Podemos actualizar esta política. La fecha de arriba indica la última revisión.
